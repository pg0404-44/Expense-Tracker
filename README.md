# Expense Tracker Web App

A full-stack expense tracking application built using Node.js, Express, MongoDB, and EJS.

---

## 🚀 Features

- User authentication (Signup/Login/Logout)
- Session-based authentication using Passport.js
- Create, update, delete expenses
- Category-wise expense tracking
- Advanced filtering (date, category, amount, keyword)
- Pagination system
- Analytics dashboard (Chart.js)
- Monthly & category-wise insights
- Protected routes with authorization (owner-based access)

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB & Mongoose
- EJS Templates
- Bootstrap
- Passport.js
- Chart.js

---

## 📊 Key Features

- Secure authentication system
- RESTful route structure
- Data aggregation using MongoDB
- Responsive UI
- Real-time filtering & search
